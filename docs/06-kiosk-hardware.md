## 3. 핀 배치 (ESP32 DevKitC)

| 기능 | GPIO | 연결 | 설정 |
|---|---|---|---|
| LED 1 | 25 | GPIO → 220Ω → LED(+) → LED(−) → GND | OUTPUT |
| LED 2 | 26 | 〃 | OUTPUT |
| LED 3 | 27 | 〃 | OUTPUT |
| 문 1 | 32 | 리드 스위치 한쪽 → GPIO, 다른 쪽 → GND | INPUT_PULLUP |
| 문 2 | 33 | 〃 | INPUT_PULLUP |
| 문 3 | 19 | 〃 | INPUT_PULLUP |
| 인체감지 OUT | 34 | PIR OUT → GPIO34, VCC → **5V(VIN)**, GND → GND | INPUT (입력 전용 핀) |
| 부저 (선택) | 23 | GPIO → 부저(+), 부저(−) → GND | OUTPUT |

**핀 선택 이유**
- GPIO 0, 2, 5, 12, 15는 부팅 모드에 영향을 주는 핀(스트래핑 핀)이라 피했다.
- GPIO 34~39는 입력 전용이라 센서 입력에만 쓴다.
- 문 센서는 **풀업 + GND 연결** 방식: 자석이 붙으면(문 닫힘) LOW, 떨어지면(문 열림) HIGH.
  → 선이 빠지면 HIGH = "열림"으로 읽혀서 **고장 나도 안전한 쪽(열림 경고)으로** 동작한다.

## 4. 시리얼 프로토콜 (태블릿 ↔ ESP32)

- USB 시리얼, **115200bps, 8N1**
- **한 줄 = 한 메시지**, 끝은 `\n`, ASCII 텍스트
- 사람이 시리얼 모니터로 직접 읽고 칠 수 있게 텍스트로 설계 (디버깅 쉬움)

### 태블릿 → ESP32 (명령)
| 명령 | 의미 | 응답 |
|---|---|---|
| `PING` | 연결 확인 (5초마다) | `PONG` |
| `LED <n> <ON\|OFF\|BLINK>` | n번 칸 LED 제어 | `OK` 또는 `ERR <이유>` |
| `LED ALL OFF` | 전체 끄기 | `OK` |
| `BUZZ <ms>` | 부저 울리기 | `OK` |
| `STATUS?` | 현재 문 상태 요청 | `STATUS 1:CLOSED 2:OPEN 3:CLOSED` |

### ESP32 → 태블릿 (이벤트)
| 메시지 | 의미 | 언제 |
|---|---|---|
| `READY pickbox-fw <버전>` | 부팅 완료 | 전원 켜질 때 |
| `DOOR <n> <OPEN\|CLOSED>` | 문 상태 변화 | 변화 발생 시 (50ms 디바운스) |
| `MOTION` | 사람 감지 | PIR 신호가 LOW→HIGH로 바뀔 때 |

### 예시
```
← READY pickbox-fw 0.1.0
→ STATUS?
← STATUS 1:CLOSED 2:CLOSED 3:CLOSED
← MOTION
→ LED 2 BLINK
← OK
← DOOR 2 OPEN
← DOOR 2 CLOSED
→ LED 2 ON
← OK
```

### 역할 나누기
| 펌웨어가 하는 것 | 키오스크 앱이 하는 것 |
|---|---|
| LED 깜빡임 타이밍 (`millis()` 기반, `delay()` 사용 금지) | 어떤 칸 LED를 어떻게 할지 결정 (서버 응답 기준) |
| 문 센서 디바운스, 변화가 있을 때만 보고 | 문 이벤트를 서버에 전달 |
| PIR 신호 변화 보고 | "어서오세요" 음성 재생 여부 (대기 화면일 때만, 30초 쿨다운) |
| **업무 로직 없음** | 화면 흐름, 타임아웃 표시 |

## 5. 키오스크 앱 (Android) 구현 메모
- **USB 권한**: `usb_device_filter.xml`에 CP2102 (VID `0x10C4`, PID `0xEA60`) 등록 → 연결 시 앱 자동 실행 + 권한 요청
- **연결 끊김 대응**: `PONG`이 15초 이상 없으면 "하드웨어 연결 확인 필요" 표시 + 하트비트에 `serialConnected=false` 보고, 재연결 시 `STATUS?`로 상태 재동기화
- **부팅·재연결 시 LED 동기화**: 서버 하트비트 응답의 `lockers[].led` 값으로 LED 3개를 다시 맞춘다
- **화면**: 항상 켜짐(`FLAG_KEEP_SCREEN_ON`), 전체화면(시스템 바 숨김)
- **QR 스캔**: 전면 카메라 + ML Kit, 같은 QR 연속 인식 방지(3초)
- **음성**: TextToSpeech (`Locale.KOREAN`), 앱 시작 시 미리 초기화
- **관리자 메뉴**: 로고 5번 탭 + PIN → 서버 주소·기기 키 입력, 시리얼 상태, LED/부저 테스트, 시리얼 로그 보기

### 키오스크 모드 (확장 단계)
| 단계 | 방법 | 효과 |
|---|---|---|
| 1 | 전체화면 + 화면 켜짐 유지 | MVP |
| 2 | HOME 런처로 등록 (`CATEGORY_HOME`) | 홈 버튼 눌러도 PickBox로 |
| 3 | Lock Task 모드 | 다른 앱으로 못 나감 |
| 4 | Device Owner 설정 (`adb shell dpm set-device-owner`) | 확인 창 없는 Lock Task, 앱 자동 업데이트 |

## 6. 보관함 제작 메모
- 칸 하나 크기는 손바닥만 한 물건(이어폰, 지갑, 책)이 들어갈 정도면 충분
- 문은 경첩 대신 **아래쪽에 테이프 힌지**로 시작해도 된다
- 리드 스위치는 **틀(고정부)**에, 자석은 **문(움직이는 부분)**에 붙이고 닫혔을 때 1cm 이내로 맞닿게
- 선 정리: 칸 뒤쪽으로 모아 브레드보드까지. 나중에 만능기판으로 납땜하면 시연용으로 튼튼해진다
