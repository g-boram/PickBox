# 07. 개발 로드맵

원칙
- **한 단계가 끝나면 배포까지** 한다. 중간에 멈춰도 그 시점까지가 완성품이 되도록.
- 처음 배우는 영역(Kotlin, ESP32)은 **개념 → 작은 실습 → 프로젝트 적용** 순서.
- 마감은 정하지 않는다. 대신 단계별 체크리스트로 진행 상황을 본다.
